# getsuricata.com

אתר סטטי, קובץ אחד: `index.html`. מוגש ב-Netlify כמו שהוא, בלי build.
האתר מתאר את האפליקציה (`~/smartinvest`) ולא מוסיף לה. ההכרעות ב-`DECISIONS.md`.

## מה יש כאן

| נתיב | מה |
|---|---|
| `index.html` | כל האתר: עיצוב, תוכן וסקריפט |
| `fonts/` | Heebo, Assistant, Archivo · אותם קבצים כמו ב-`smartinvest/public/fonts` |
| `img/` | רצועת הסוואנה ופרוסה ממנה, מהאפליקציה (PNG המקור, ו-WebP שמוגש) |
| `scripts/check-sync.mjs` | בודק שהאתר לא מתאר יכולת שכבויה באפליקציה, ושהמקורות והאקדמיה זהים לה |

## בדיקת סנכרון עם האפליקציה

```sh
node scripts/check-sync.mjs                  # האפליקציה ב-~/smartinvest
node scripts/check-sync.mjs ../smartinvest   # או נתיב אחר
SMARTINVEST=/path/to/app node scripts/check-sync.mjs
```

Node 18 ומעלה, בלי תלויות. יציאה 0: האתר תואם. יציאה 1: רשימת הפערים.

**מתי להריץ:** לפני כל פריסה של האתר, ואחרי כל שינוי באפליקציה ב-`features.js`, ב-`DataSourcesCard.jsx` או באקדמיה.

**מה נבדק:**
- **דגלים:** לכל דגל כבוי ב-`features.js` יש רשימת ביטויים (`TERMS` בסקריפט) שאסור לאתר לומר. דגל כבוי שאין לו רשימה נכשל, עד שמוסיפים לו אחת. עמוד המחשבונים של האתר והפסקה המשפטית שבפוטר לא נסרקים: הם לא מתארים את האפליקציה.
- **"מאיפה הנתונים":** הטבלה באתר זהה ל-`ROWS`, שורה בשורה ובאותו סדר, וגם המשפט שמעליה.
- **אקדמיה:** המסלולים, מספר השיעורים בכל מסלול והסכום, לפי `academyContent.json`, בלי שיעורים שהדגל שלהם כבוי.

**כשהבדיקה נכשלת על טבלת המקורות:** מעתיקים את השורות מ-`DataSourcesCard.jsx` לבלוק `data-sources` ב-`index.html`, באותו סדר ובאותו נוסח.
